# 🎓 CampusBuddy AI

> **Your AI-powered college companion**

CampusBuddy AI is a student-focused web application designed to help college students manage their studies, assignments, notes, quizzes, and study plans in one simple dashboard.

## 💡 Why I Built It

I built CampusBuddy AI for a college friend who was constantly switching between notes, assignments, deadlines, and different study tools.

The goal is simple:

**Make studying more organized, easier, and less stressful.**

## ✨ Features

* 🤖 **AI Tutor** – Ask questions and get simple explanations.
* 📝 **Notes Summarizer** – Convert long notes into short summaries.
* 🧠 **Quiz Generator** – Generate practice questions for different subjects.
* 📅 **Study Planner** – Organize study sessions and subjects.
* ✅ **Task Manager** – Manage assignments and deadlines.
* 📊 **Student Dashboard** – View study progress and upcoming tasks.
* 📱 **Responsive Design** – Works on desktop, tablet, and mobile.
* 🎨 **Student-Friendly UI** – Clean and easy-to-use interface.

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application functionality

### 🤖 AI

The current frontend version includes demo/local AI responses in JavaScript.

The project is designed to be connected to an **open-source AI model** such as:

* Qwen
* Llama
* Gemma

The planned full version will use an open-source AI model through a backend API.

## 🚀 How to Run

### Method 1 — Open Directly

1. Download or clone this repository.
2. Open the `CampusBuddy-AI` folder.
3. Open `index.html`.
4. The website will open in your browser.

### Method 2 — Using VS Code

1. Open the project in **VS Code**.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

## 🎯 How to Use

1. Open the CampusBuddy AI dashboard.
2. Go to **AI Tutor** and ask a study question.
3. Use **Notes Summarizer** to summarize notes.
4. Generate quizzes for different subjects.
5. Create a study plan.
6. Add assignments and deadlines.
7. Track your study progress.
